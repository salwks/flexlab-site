# 조선 회화 아카이브 화가 마스터 목록

> 목적: 유명 화가 몇 명을 임의로 고르는 방식이 아니라, 조선 회화사·도화서/차비대령화원·화원 가문·실경산수·장르 전문화가를 교차검증하여 작품 수집 누락을 줄인다.
>
> 중요: 이 문서는 “조선의 모든 화가”라는 완전명부가 아니다. 1783~1881년 『내각일력』에서 확인되는 차비대령화원만 약 104명이다. 따라서 **미술사 핵심 명단**과 **화원 전체 대조 명단**을 별도로 관리한다.

## A. 기준 사료/연구

1. 한국민족문화대백과사전 「회화」
   - https://encykorea.aks.ac.kr/Article/E0065600
   - 조선 회화를 초기(1392~1550경) / 중기(1550~1700경) / 후기(1700~1850경) / 말기(1850~1910경)로 구분.
2. 한국민족문화대백과사전 「차비대령화원」
   - https://encykorea.aks.ac.kr/Article/E0055150
   - 1783~1881년 약 104명 확인.
3. 국사편찬위원회 우리역사넷
   - 도화서·화원, 진경산수, 화원 가문 자료 교차검증.
4. 국립중앙박물관
   - 소장품·서화실·「우리 강산을 그리다」 전시로 현존작/작가/시대 확인.
5. Wikimedia Commons / 공유마당
   - 실제 이미지 파일명과 이용조건 확인용. **작가 선정의 1차 사료로 쓰지 않는다.**

## B. 미술사 핵심 화가

### 1) 조선 초기

추가 대조: 최경, 강희맹 등.  
※ 추가 대조 화가는 다른 공신력 있는 자료에서 화가 활동이 확인되더라도, 현존작/귀속을 별도로 확인한 뒤 사이트에 넣는다.

## C. 차비대령화원 별도 트랙

한국민족문화대백과사전은 1783~1881년 『내각일력』에 기록된 차비대령화원을 약 104명으로 본다.
현재 명시적으로 확인된 핵심 인물:
김응환, 신한평, 김홍도, 이인문, 김득신, 김하종, 장한종, 이한철,
유숙, 이형록, 백은배, 유운홍.

이 목록을 104명 전체 명부와 계속 대조하되, **이름만 존재하고 현존작이 확인되지 않으면 갤러리 카드로 만들지 않는다.**

## D. 화원 가문 별도 트랙

개성 김씨 화원 가문:
김응환 → 김득신·김석신·김양신 → 김건종·김수종·김하종

혼인/연결 화원:
이명기, 장한종 등

가문 계보는 누락 화가를 찾는 도구로 사용하며, 작품 귀속 검증은 별도로 한다.

## E. 사이트 등록 상태 원칙

- [A] 작가와 작품 모두 기관/공공 자료로 확인 + 전체 이미지 확보 → 즉시 등록
- [B] 작가/작품은 확인됐으나 전체 이미지 미확보 → 조사 큐
- [C] 전칭/귀속 논쟁 작품 → 전칭을 명시하고 등록 여부 별도 판단
- [D] 세부 크롭만 존재 → 메인 갤러리 등록 금지
- [E] 사진·유물·재현 이미지 → 회화 아카이브 등록 금지

## F. 이미지 검증 규칙

1. 전체 작품 또는 독립된 완전한 한 폭/한 면만 쓴다.
2. 박물관 확대용 세부 크롭을 작품 전체로 등록하지 않는다.
3. 병풍·화첩은 ‘n폭 / n면’임을 제목에 표시한다.
4. Commons 파일명은 검색 결과가 아니라 실제 File 페이지에서 확인한다.
5. 기관 직접 이미지 URL은 소장품 페이지와 대응 관계를 확인한다.
6. 전칭(傳稱)·모사본·대한제국 경계자료는 제목/시대에 표시한다.
7. 이용조건은 작품 원저작권과 디지털 이미지 이용조건을 구분한다.

## G. 미반영 조사 큐 (2026-10-19 대조 후)

양팽손, 최숙창, 이장손, 황집중, 김희성, 이희영, 장준량, 신학권.

각 화가의 실제 전승 작품·미확보 이미지·귀속 충돌은 [화가별 검증 기록](PAINTER_AUDIT_2026-10-19.md#보류-목록과-재조사-조건)에 남겼다. 이 명단은 작품이 없다는 판정이 아니다.

## H. 현 단계 (2026-10-19)

- B절의 중복·이명을 정리한 핵심 명단은 **82명**이다. 종전의 “89명”은 실제 본문 명단과 맞지 않아 정정했다.
- 실행된 `index.html` 기준 변경 전은 **260개 카드·핵심 51명**, 이번 검증 추가는 **27명·36개 카드**다.
- 현재 **296개 카드**, 핵심 화가 **75/82명**, G절에서 추가 대조한 4명 중 **3/4명**에 작품이 연결돼 있다. 합계 **78/86명**이며 전칭도 포함한 등록 현황이다.
- 기존 조사 큐에 남아 있던 김시·조속·조지운은 이미 등록돼 있어 중복 추가하지 않았다. 반대로 핵심 명단에 있으면서 큐에는 없던 박제가도 이번에 대조·추가했다.
- 종전 “49명”과 구두로 언급된 “약 50명” 대신, 합작의 작가를 나누고 전칭·추정 접두어와 이명을 정규화한 실제 집계다. 기존 작품의 존재 확인과 신규 작품의 귀속·전체 이미지 검증은 구분한다.
